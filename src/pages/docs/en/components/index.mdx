# Components

<div class="doc-intro">
  <p>All primitive UI building blocks in Astro Micro are Lit 3 Web Components living in <code>src/webs/apex/</code>. They use Shadow DOM for style encapsulation and are usable in any HTML page or framework.</p>
</div>

## How Web Components Work Here

- Built with **Lit 3** — reactive properties, efficient updates, Shadow DOM by default
- **Exception**: `web-board` uses light DOM for global style access
- Each component is a single `.js` file — no build step needed to use them
- Load via `<script type="module">` or import in your Astro frontmatter

## Loading a Component

**Script tag (recommended for most cases):**
```html
<script type="module" src="/src/webs/apex/web-button.js"></script>
```

**Frontmatter import (bundles into page output):**
```astro
---
import '@/webs/apex/web-button.js';
---
```

## Common Props

These props are available on most `web-*` components:

| Prop | Type | Default | Description |
|---|---|---|---|
| `ui` | string | `'modern'` | UI variant: `modern` \| `spatial` (glassmorphism) |
| `theme` | string | `''` | ApexUI theme override for this component |
| `mainColors` | string | `''` | Pipe-separated 5 color names: `primary\|base-100\|base-200\|base-300\|base-content` |
| `textColor` | string | `''` | Text color — must be a CSS variable reference |

## Events

All custom events use `bubbles: true` and `composed: true` to cross Shadow DOM boundaries. Listen at the document level or any ancestor element:

```js
document.addEventListener('web-item-select', e => {
  console.log(e.detail);
});
```

## Quick Example

A minimal page using three components:

```astro
---
// src/pages/example.astro
---

<web-alert type="info" title="Notice">This is a demo page.</web-alert>

<web-button type="fill" color="primary">Get Started</web-button>

<web-loader width="100%" height="200px" rounded></web-loader>

<script type="module" src="/src/webs/apex/web-alert.js"></script>
<script type="module" src="/src/webs/apex/web-button.js"></script>
<script type="module" src="/src/webs/apex/web-loader.js"></script>
```
